# README guideline

Status: **plan**. Applies to every OWD repository and to generated starters:
`core`, the framework adapters, every `*-desktop` distribution, every extension
package (`<framework>-app-*`, `-module-*`, `-theme-*`, `-kit-*`) and the starter
generated by `create-owd`.

The goal is that a reader recognizes an OWD README in the first screen: the same
logo, a centered title, a one-line tagline that names `@owdproject/core`.

## Required header

Every README starts with this block, before any `##` section:

```html
<p align="center">
  <img width="160" height="160" src="https://avatars.githubusercontent.com/u/65117737?s=160&v=4" />
</p>
<h1 align="center">@owdproject/core</h1>
<h3 align="center">
  Powered by <code>@owdproject/core</code> — one line that says what this artifact is.
</h3>
```

This is the exact header already used by the generated starter
(`nuxt-desktop/template-blueprint/README.md:1-7`, identical to
`nuxt-desktop/template/README.md:1-7`). The Nuxt distribution README uses the same
structural shape but an older tagline (`nuxt-desktop/README.md:1-6`, H1 *"Open Web
Desktop"* with no engine mention) and should be migrated to the engine-naming rule
below. Do not replace the header with a plain `# Title`.

## Rules

1. **Logo first.** The centered `<img>` above is the OWD mark. Do not swap it for a
   different asset or drop it.
2. **Centered title.** `<h1 align="center">` with the artifact's real name —
   `@owdproject/core`, `@owdproject/nuxt`, `Nuxt Desktop`, …
3. **Centered tagline.** `<h3 align="center">` written in English, one line, saying
   what the artifact is. For a distribution or starter, name the engine:
   *"Powered by `@owdproject/core`"* + the framework.
4. **Optional rows.** A badge row and a nav-links row (`<p align="center">` with
   `Overview · Docs · Community`) may follow the tagline. This is the
   `<div align="center">` layout used by `core/README.md:1-27`; keep it centered and
   use that README's real anchor list as the model.
5. **Language.** READMEs are English. Internal planning text is not a README.
6. **Generated starters are not hand-edited.** A distribution's `template/README.md`
   is produced by the CLI from the blueprint; fix the blueprint and regenerate.

## Do not

- Do not start with a bare `# react-desktop` heading and prose.
- Do not invent a second visual identity per distribution; the framework changes the
  tagline and the body, not the header shape.
- Do not link private planning repositories.
